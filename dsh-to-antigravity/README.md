# DSH → Antigravity · 开发版

DSH Desktop 是发起方，Antigravity Desktop 是执行方。目标为 Hydrogen High；不会修改 DSH 自己的模型。

在整个项目根目录按主 README 配置后，运行 `./scripts/install.sh dsh`。插件加入 DSH Desktop 配置，保留原有插件。调用 antigravity_submit_task，提交后用 antigravity_get_result 查询；来源会话由 DSH 实际执行环境自动取得，不让模型编造。

已在 desktop-smoke-workspace 的现有会话做过一次真实问候测试。目标任务在 Antigravity Bridge Dev 项目中可见。详细进度在原生窗口查看；监控地址和限制见上级 README。
